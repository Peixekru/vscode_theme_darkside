# 🌒 DarkSide Theme

**DarkSide** is a sleek, dark theme for Visual Studio Code, designed for those who seek **visual comfort**, **balanced contrast**, and **minimalist focus**.

🔤 **Font used in the screenshots:** Fira Code, MesloLGS NF  
🎨 **Design focus:** soft dark tones, clean highlights, less visual noise  
🧩 **Compatible with:** Visual Studio Code, Cursor and Trae IDE

## 🚀 Installation

1. Open the Extensions sidebar in VS Code  
2. Search for `DarkSide`  
3. Click **Install**  
4. Open the Command Palette with `Ctrl+Shift+P` or `⇧⌘P`  
5. Choose `Preferences: Color Theme` → **DarkSide Theme**
